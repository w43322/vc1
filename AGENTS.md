# Virtual City decomp — agent guide

Decomp of `VirtualCity.Unwrapped.exe` (SHA-256 in README): a VC9 SP1 x86 `/GL /LTCG` rebuild compared with reccmp.

Every recovered function needs **Ghidra evidence from the original** and a **reccmp diff of the recompiled bytes**; put the evidence in source comments. Do not spawn sub-agents, upload game assets, or commit `ghidra/`, `build/`, `.mcp.json`, `reccmp-build.yml`, `reccmp-user.yml` or anything under `Virtual-City_Win_EN_Full/` (stage files by name).

## Before you start

- `git status --short`; keep other people's uncommitted files; never reset or clean the tree.
- Every Ghidra read names program `VirtualCity.Unwrapped.exe`. Game entry is stdcall `WinMain` `0x00486b00` (`src/kdcore/win_main.cpp`); the PE entry is stock `WinMainCRTStartup`. No fake `main`.
- Scratch scripts and dumps go in the session scratch directory and are deleted after the round. `tools/` holds only documented helpers; do not delete a standalone diagnostic just because no build step calls it.
- Machine paths come from `tools/workspace.ps1` (parameter, then `VC1_GHIDRA_HOME` / `VC1_GHIDRA_MCP_DIR`, then the default); do not hardcode them. `.mcp.json` is generated by `tools/setup-mcp.ps1`.

## One round

1. `tools/open-ghidra.ps1`; `tools/compare-reccmp.ps1 -ResetBaseline`.
2. MCP (`list_instances`, `connect_instance VirtualCity`). For each address, read just enough, then write its C++ before dumping the next one. **Never write Ghidra through MCP.**
3. `tools/build-vc9.cmd`, `tools/compare-reccmp.ps1`. Read the asm diff of every function you touched (`tools/diff-reccmp.ps1 0x...`), and `VC1-data.txt` / `VC1-vtable.txt` after `GLOBAL` / `VTABLE` changes.
4. `tools/close-ghidra.ps1`, then `tools/import-ghidra.ps1` (the only Ghidra write path).
5. Commit only when the user asked for it.

If a read shows existing source, a marker, a flag, `verified.csv`, a tool or this file is wrong, fix it in the same round.

## Evidence and identification

- Decompiler output is the main evidence; asm decides ABI: parameter registers (LTCG uses EAX/ECX/EDX/ESI/EDI/EBX), return register, `RET N`, from at least one caller. Ghidra often inverts bool returns; trust `TEST`/`Jcc`.
- Find functions from unique literals (`search_strings`, `get_xrefs_to`; keep original typos), address gaps next to mapped functions, callers of mapped helpers, registration tables, and Squirrel type tags (`OT_NULL=0x1000001`, `OT_INTEGER=0x5000002`, `OT_FLOAT=0x5000004`, `OT_STRING=0x8000010`, `OT_TABLE=0xa000020`, `OT_ARRAY=0x8000040`, `OT_INSTANCE=0xa008000`, refcounted `0x8000000`).
- Leave unmapped what has no unique body: functions LTCG inlined everywhere, blobs merging several source functions. ICF-folded identical functions get `FOLDED` on every source name.
- A 0% match on a new name usually means the wrong overload/symbol; use the mangled name as the name comment.
- `tools/disasm-orig.py 0x...` (or `--dwords`) gives raw original views; `tools/stackcmp-reccmp.ps1` compares stack slots.

## Writing source

- VC9-compatible C++ only (no `auto`, `nullptr`, range-for, lambdas), `/GR-`, no `/EH`, `/GS-`, keep `/GL /LTCG`. No inline asm, no invented mappings.
- `// FUNCTION: VC1 0x...` directly above the definition, **address-sorted within the file**. `STUB` only for empty/dishonest bodies.
- `GLOBAL` on the definition (external linkage, not `static`). `VTABLE` above the type, one per original table with the `{for `Base'}` name for multiple inheritance. `SYNTHETIC` name comments for compiler-generated symbols (scalar deleting destructors, adjustor thunks such as `src/app/adjustor_thunks.h`). `STRING` above the line with the literal, each address once; a literal shared by functions is one `extern const char` array marked `GLOBAL`.
- Constructors are `T::T()`; never write vptrs by hand. Interface members released in reverse order are `KdRef<T>`. `IAbstract` is always a base. `IUnknown` methods stay pure.
- Every original callee has a VA: call a mapped function or mark the callee (`FUNCTION`/`STUB`). Name slots and helpers by behaviour, not offset; say when a name is a guess.
- Arrays the original unrolls (construct, destroy, mark) are separate members. Inline-only helpers without an original address are `__forceinline`; `__declspec(noinline)` is fine where the original keeps a helper out of line at every call. Before forcing either on a shared helper, compare the whole report (forcing `SQVM::Pop` inline cost 0.6% match-weighted).
- Recovered code never branches on the target. SDL3 needs go in `src/imports/sdl3/` (one file per DLL; `include/` stands in for the SDK). `cmake/kdcore.cmake` keeps the reference translation-unit order.
- Adjacent globals the original indexes as one block (a `RECT`, the event queue at `0x004ed144`) must be one C++ object.

## Libraries

Vendored bodies stay upstream; mapping is comments only, except evidence-backed `// VC1:` patches and force-included headers. A `/FI` header must also be an `OBJECT_DEPENDS` of its sources, or edits do not rebuild them.

- **Squirrel 2.2.3**: `FUNCTION` on implementations in address order, otherwise name comments in headers. Patches are listed in `third_party/squirrel223/PROVENANCE.md`. Host forks (system, math, io) live in `src/kdcore/`. `0x00497490` is the host heap, not `sq_malloc`.
- **SqPlus**: patches marked `// VC1:` (e.g. `GetInstance` ignores the typetag result); strings are `vc1::KdString`.
- **libpng 1.0.2 / zlib 1.1.3**: `PNG_NO_READ_INTERLACING` (marked `pngconf.h` switch); `memcmp` is the game's `MemCompare` (`0x00499d00`) via `src/kdcore/kd_string_c.h`; reads go through the KD file layer. Keep `png_struct` 0x168 / `png_info` 0x48.
- **jpgd 0.93b**: no MMX/asm; `memcpy` is a CRT call (`jpgd_vc1.h`); `use_mmx` is kept and read at EOI in `process_markers`.
- **Pyro** (proprietary, recovered in `src/pyro/`): built without the memcpy/memset intrinsics (`pyro_crt.h`).
- **klibc** scanf, **libtga**, **LZMA SDK 4.57** (`_LZMA_IN_CB`, `_LZMA_PROB32`), **Boost 1.41.0** pool, **pthreads-win32 2.8.0** (`VC-static`, `__CLEANUP_C`): name comments in each library's `*_vc1.h` / header. sqstdio and libtga use KD file I/O with null-handle checks (`src/kdcore/kd_stdio.h`).
- CRT and source-less libraries: `config/verified.csv` (`address|type|name|symbol`). Never use `ignore-functions`.

## reccmp

`tools/compare-reccmp.ps1` runs decomplint and asmcmp (both can fail the script) plus diffs, datacmp, vtable and roadmap reports in `build/vc9/reports/`. Report per-function similarity; it is not game completion. `Match ... collides` is expected only on `FOLDED` addresses.

The original EXE has no relocation table, so reccmp cannot find its strings, globals or float constants by itself; unmapped ones show as raw addresses or `<OFFSETn>`. Map them with source markers, or with `string` / `global` rows in `config/verified.csv` and `float` rows in `config/floats.csv`.

## Runtime

Run from `Virtual-City_Win_EN_Full/VirtualCity`. `tools/run-debug.py --timeout 20` prints KdLog, script errors and symbolized crashes (`--bp` takes recompiled VAs from the `.map`, `--click FX,FY@T` clicks, `--keep` leaves the game running; close it before the next run). `tools/run-screenshot.py` captures a frame. Game scripts are compiled Squirrel; `tools/decompile-nut.ps1` writes readable copies to `Virtual-City_Win_EN_Full/nut-src/`.

Status: the menu, intro comic with Pyro particles, BASS music and sound, and Level_01_01 run without script errors; the SDL3 build ran Level_01_05 before the imports refactor and has not been rerun since. When a script reports a missing component or method, check the factory and `GetMember` first; a stub that returns 0 fails far away. Always rebuild after reverting an experiment before measuring.
